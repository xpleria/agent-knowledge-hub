# Godot index

- **Scope:** Technology Godot: which Godot-specific pages exist, and how far do they apply?
- **Keywords:** Godot, Godot 4, game engine, GDScript, traps, UI, layout, input, web export, game client, game server
- **Status:** current
- **Updated:** 2026-11-07
- **Sources:** the Godot pages' own sources

Godot pages hold traps that are specific to Godot. Each page is labelled with its version. They are not project-invariant rules: check the Godot version you use before applying a trap, because behaviour changes between releases.

Only broadly useful, reusable traps belong here. A project's own scene or code pattern belongs in that project.

Facets are chosen by content. A game-server facet is a possible future facet; none exists yet, and no folder is created until it holds at least two pages. Until other facets exist, this technology's pages sit directly in this folder.

## Reading guide

- Working on Godot 4 UI, layout, input or viewport code: read [godot-ui-traps.md](godot-ui-traps.md) first, then check the Godot version you use.
- Any other Godot facet: no page yet.
